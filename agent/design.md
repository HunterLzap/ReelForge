## 1. 逐模块成熟产品对标矩阵（取优避坑）

| ReelForge 模块 | 对标产品 | 重点借鉴的交互精华 | 必须回避的坑 / 专属增强 |
|---|---|---|---|
| **模型检测、下载与路由中心** | **Magpie**（开源 macOS 网关） | **Provider 集中托管 + 单表角色映射（Role → Model 下拉直选）**；自动探测本机端口（Magpie `3425`、Ollama `11434`、LM Studio `1234`）与云端 API 同构接入。 | 补足媒体模型下载体验：**本机一键探测 + 镜像下载进度条**；在 2C2G 低内存服务器上自动锁定走云端 API，防止内存溢出。 |
| **主剪辑工作台骨架与时间轴** | **CapCut Web / 剪映** | **4 区黄金非编布局**（左竖排 Icon Rail + 可折叠资源抽屉、中上舞台、右上上下文检视器、下半屏通栏多轨时间轴）；顶部快捷操作条（撤销/分割/删除/吸附/缩放）；媒体分色与单轨锁定/静音。 | 去掉传统剪映黑密压抑感和广告入口；采用方案 A 浅色分层 + 左抽屉直接承载文稿/字幕/批注。 |
| **文本删字与口误清理** | **Descript** | 左栏文稿与主轨双向实时绑定、点字跳帧；自动标灰静音停顿 `[0.8s]`、口癖词与重说重复句；**非破坏性删改**且点击可恢复。 | 增加「自然呼吸留白滑块（默认 80ms）」与项目专有名词批量替换。 |
| **录屏包装与放大标注** | **Screen Studio** | 录屏自动加圆角窗口 + 柔和渐变壁纸衬底 + 阴影；平滑贝塞尔 `zoom_focus` 推拉与聚光灯高亮，免去手 K 关键帧。 | 支持导入任意已有 `.mov/.mp4` 录屏后在画布框选加放大/聚光灯/气泡标注。 |
| **画布框选审片批注** | **Frame.io** | 暂停帧直接画框留批注；时间轴标尺同步展示彩色 Pin 标记点，点击秒跳对应帧。 | 打通「Pin → 内置 AI / 外部 MCP」闭环，AI 直接读截帧+坐标修片。 |
| **极速字幕精校** | **飞书妙记 / 剪映字幕列表** | 紧凑双列表格（时间码 + 可编辑文本框 + 字数预警），点句跳帧、回车拆句、快捷键合并。 | 绝不把改字幕藏在二级弹窗里，录屏模式下常驻左抽屉直接开改。 |
| **对话编导与 Skill** | **ChatCut** | 对话起手思路、一键套用同款 Skill 模板、外部 MCP 协同。 | **避坑**：① 绝不隐藏高频剪辑按钮；② 绝不做不可撤销黑盒修改；③ 内置 `Cmd+K` 全局命令面板防迷路。 |

## 2. 拒绝重复造轮子：成熟开源前端组件栈

严禁手写弹窗、下拉、分栏拖拽、音频波形、虚拟滚动与命令面板等基础控件：

| 能力域 | 选定开源库 / 方案 | 选型依据与集成要点 |
|---|---|---|
| **基础组件与无障碍** | **`shadcn/ui` + `@radix-ui/react-*` + Tailwind CSS** | 源码可控、天然适配方案 A 浅色 Token；覆盖 `Dialog`, `Sheet`, `Popover`, `DropdownMenu`, `Select`, `Tabs`, `Slider`, `Switch`, `Tooltip`, `ContextMenu`。彻底消灭原生 `<select>` / `Choose File` / `alert()` / `confirm()`。 |
| **可拖拽分栏骨架** | **`react-resizable-panels`** | 支撑 CapCut 4 区左抽屉、右上检视器宽度、下半屏时间轴高度的自由拖拉与 `localStorage` 布局持久化。 |
| **全局直达命令面板** | **`cmdk`** | `Cmd+K` 模糊搜索所有动作/Skill/面板跳转，根治功能多找不到入口的问题。 |
| **动态预览与组件注册** | **`@remotion/player` + `remotion` + `remocn` 范式** | `motion/` 与 `skills/` 采用 `remocn`（shadcn 风格可复制 Remotion 组件）范式；用户浏览器直出预览，零服务端渲染压力。 |
| **5 轨可视化时间轴** | **Remotion Timeline 架构 + `@dnd-kit/core`** | 复用成熟拖拽/指针原语搭配轻量毫秒↔像素标尺层，完美适配 5 条语义轨道 + `ReviewPin` + 非破坏性 `Transcript` 联动。 |
| **真实音频波形** | **`wavesurfer.js`** | 音频轨与试听面板渲染真实波形，肉眼直观看见静音空白段。 |
| **万行级流畅字幕表** | **`@tanstack/react-virtual`** | 长录屏数百上千条字幕行内编辑稳定 60fps。 |
| **状态、快捷键与提示** | **`zustand` + `react-hotkeys-hook` + `sonner` + `lucide-react`** | 分片订阅防止拖播放头卡顿；快捷键自动避让输入框；清爽轻量 Toast 提示。 |

## 3. 方案 A（浅色清爽创作台）视觉 Token 与红线

### 3.1 色彩 Token
```css
:root {
  --bg-app: #f8fafc;          /* 外围底色 */
  --bg-surface: #ffffff;      /* 顶栏、面板、检视器、弹窗 */
  --bg-stage: #eef2f6;        /* 视频画布舞台（中性冷灰托出深浅视频） */
  --bg-control: #f1f5f9;      /* 次级按钮与输入槽底色 */
  --border-subtle: #e2e8f0;
  --ink-primary: #0f172a;
  --ink-muted: #64748b;
  --accent: #2563eb;          /* 唯一主强调色（克制靛蓝） */
  --accent-hover: #1d4ed8;
  --accent-soft: #eff6ff;
  --success: #10b981;
  --warning: #d97706;
  --danger: #e11d48;
}
```

### 3.2 时间轴 5 轨低饱和语义色（3px 左色条 + 柔底）
* 主视频轨 `main_video`：`#3b82f6` / `#eff6ff`（缺料占位槽使用 `#94a3b8` 虚线边框）
* 贴片轨 `overlay`：`#06b6d4` / `#ecfeff`
* 录屏标注轨 `annotation`：`#8b5cf6` / `#f5f3ff`
* 字幕轨 `subtitle`：`#6366f1` / `#eef2ff`
* 音频轨 `audio`：`#10b981` / `#ecfdf5`
* 审片批注 `ReviewPin`：`#f59e0b` / `#fffbeb`（仅用于时间轴标尺小号标记点与待处理角标）

### 3.3 视觉红线（Hard Anti-Patterns）
1. 任意视口同一时刻最多只保留 **1 个实心蓝底主按钮**；
2. 所有时间码、FPS、像素与配额数值强制 `font-variant-numeric: tabular-nums` 等宽显示；
3. 品牌名（`ReelForge · 映铸`）与当前项目名（`← 作品库 / 项目名`）必须用明确面包屑隔离；
4. 切到「导出与发布」阶段时必须彻底隐藏剪辑时间轴与单幕属性表单；
5. 严禁把 API Key / 模型下载 / MCP 配置塞进「新建作品」首屏必选项；
6. 严禁 AI 修改静默覆盖用户手调结果（必须附变更摘要与一键撤销按钮）。

### 4.3 Magpie 式「环境、模型与路由」设置中心 & 快捷键
* **Tab 1 任务路由表**：单表映射 `LLM 编导` / `VLM 识图` / `网页抽取` / `ASR 转写` / `TTS 配音` 五个角色的引擎来源、模型选择与 `[测试]` 按钮；支持自动探测并一键导入本机 Magpie 网关（`127.0.0.1:3425`）；若运行在 `cloud_2c2g` 模式则默认全走云端国内 API 并隐藏危险本地大模型选项。
* **Tab 2 本机能力探测与模型下载（仅 `local_mac` / 大内存环境解锁）**：一键扫描工具与缓存、展示体积与内存评分、默认走 `HF-Mirror` / `ModelScope` 镜像源带进度下载/取消。
* **Tab 3 云端 Key、外部 MCP 与存储管理**：配置 DeepSeek / 阿里云百炼 / 硅基流动 / 火山 / Pexels / Firecrawl 等 Key（掩码保存）；一键复制 MCP 配置；显示服务器 40G 磁盘占用明细与 `[清理缓存与代理]` 按钮。
* **核心快捷键**：`Space` 播放/暂停｜`Cmd+K` 全局命令面板｜`S` 分割片段｜`Delete` 删除选中｜`Cmd+Z` / `Cmd+Shift+Z` 撤销/重做｜`P` 框选批注｜`Z` 快速加放大框｜`Enter` / `Cmd+M` 拆句/合句。
